# AtmoSync – IoT Sensor Event Schema

## 1. Purpose

This document defines the proposed structure of IoT sensor events generated by the Python simulator and transmitted through Apache Kafka.

The schema provides a common data structure for communication between the simulator, Kafka and Snowflake ingestion pipeline.

## 2. Sensor Event Fields

| Field | Data Type | Description | Example |
|---|---|---|---|
| event_id | STRING | Unique identifier for each sensor event | EVT001 |
| container_id | STRING | Unique container identifier | CONT001 |
| timestamp | TIMESTAMP | Date and time when the event was generated, in UTC | 2026-11-05T10:30:00Z |
| temperature_c | FLOAT | Container temperature in Celsius | 8.5 |
| humidity_pct | FLOAT | Relative humidity percentage | 72.5 |
| vibration_g | FLOAT | Vibration measurement in g units | 0.35 |
| source_type | STRING | Origin of the event data | synthetic_simulated |

## 3. Sample JSON Event

```json
{
  "event_id": "EVT001",
  "container_id": "CONT001",
  "timestamp": "2026-11-05T10:30:00Z",
  "temperature_c": 8.5,
  "humidity_pct": 72.5,
  "vibration_g": 0.35,
  "source_type": "synthetic_simulated"
}
```

## 4. Proposed Kafka Topic

**Topic name:** `container_sensor_telemetry`

Purpose:
- Receive sensor events from the Python simulator.
- Support streaming of container environmental readings.
- Provide telemetry data for downstream Snowflake ingestion.

## 5. Data Validation Rules

- `event_id` must be unique for each event.
- `container_id` must not be empty.
- `timestamp` must use UTC.
- Temperature, humidity and vibration values must be numeric.
- Humidity should be between 0 and 100 percent.
- Sensor readings must be checked for missing or invalid values.
- `source_type` must identify the data origin.

## 6. Integration Responsibilities

| Component | Responsibility |
|---|---|
| Python simulator | Generate sensor events |
| Apache Kafka | Stream sensor events |
| Snowflake | Store raw sensor events |
| dbt | Validate and transform sensor data |
| Apache Superset | Visualize analytical results |
