
# AtmoSync – Team Responsibilities

## 1. Team Overview

The AtmoSync project is being developed by a four-member team. Each member has a dedicated technical or coordination responsibility.

## 2. Member-wise Responsibilities

### 1. Lav Kumar
**Role:** Project Coordinator, Documentation and Integration Manager

Responsibilities:
- Coordinate project activities and daily task allocation.
- Monitor weekly and daily milestones.
- Maintain GitHub repository structure and project documentation.
- Create and track GitHub Issues.
- Review team members' progress and pull requests.
- Maintain daily and weekly progress reports.
- Coordinate integration between Python, Kafka, Snowflake, dbt and Superset.
- Maintain meeting notes and project decisions.
- Coordinate final testing and project delivery.

### 2. Aditya Singh Bisht
**Role:** Python IoT Simulator and Apache Kafka Developer

Responsibilities:
- Develop the Python-based IoT sensor simulator.
- Generate temperature, humidity and vibration readings.
- Prepare container metadata and sample telemetry.
- Configure Kafka topics.
- Develop Kafka producer and consumer components.
- Stream sensor telemetry through Kafka.
- Validate event structure and message delivery.
- Support integration testing.

### 3. Manash Mandal
**Role:** Snowflake, dbt and SQL Data Engineer

Responsibilities:
- Configure Snowflake database, schemas and tables.
- Design raw sensor data storage.
- Develop SQL scripts for data ingestion.
- Integrate sensor telemetry with commodity pricing data.
- Develop dbt staging and transformation models.
- Implement spoilage-risk and arbitrage calculations.
- Perform data quality checks.
- Optimize analytical queries.

### 4. ANKUSH PAL
**Role:** Apache Superset, BI Dashboard and Alerts Developer

Responsibilities:
- Deploy and configure Apache Superset.
- Establish the Snowflake connection.
- Design container monitoring dashboards.
- Develop spoilage-risk visualizations.
- Display alternative-market and arbitrage opportunities.
- Define dashboard KPIs.
- Configure Slack or email notifications.
- Validate dashboard data and support final presentation.

## 3. Shared Team Responsibilities

All members are expected to:
- Follow the agreed GitHub branching strategy.
- Commit work regularly to their respective branches.
- Raise pull requests for review.
- Document technical changes.
- Participate in integration testing.
- Report blockers and progress.
- Support final project documentation.
